# Khảo sát dự án mã nguồn mở: Django

**Người thực hiện:** Đào Thị Minh Thư

**Ngày khảo sát:** 15/9/2026

| Mục | Nội dung |
|---|---|
| **Tên và chức năng** | Django — framework phát triển web bằng Python, theo kiến trúc MVT (Model-View-Template). Cung cấp sẵn ORM, hệ thống xác thực, trang quản trị (admin) và nhiều thành phần dựng sẵn giúp xây dựng ứng dụng web nhanh và an toàn. |
| **Năm khởi đầu, tác giả** | Bắt đầu năm 2003 tại tòa soạn báo Lawrence Journal-World (Mỹ), do Adrian Holovaty và Simon Willison phát triển; công bố mã nguồn mở tháng 7/2005. |
| **Giấy phép** | BSD 3-Clause — giấy phép permissive (cho phép sử dụng, sửa đổi, phân phối lại kể cả trong sản phẩm đóng), được OSI công nhận, thuộc nhóm mã nguồn mở hợp lệ. |
| **Ngôn ngữ lập trình chính** | Python |
| **Sao, fork, số người đóng góp** | Khoảng 91,1 nghìn sao, 34,3 nghìn fork, khoảng 3.000 người đóng góp trên GitHub (số liệu tại thời điểm khảo sát). |
| **Commit gần nhất** | Hoạt động rất đều đặn — dự án có lịch phát hành cố định (release cycle) hằng năm, các pull request và issue được xử lý liên tục. |
| **Số issue đang mở** | Số lượng nhỏ so với quy mô dự án trên GitHub Issues, vì Django dùng hệ thống theo dõi ticket riêng tại code.djangoproject.com. |
| **Mô hình quản trị** | Ban đầu theo mô hình BDFL kép (Holovaty và Willison), từ năm 2014 chuyển sang Technical Board — hội đồng kỹ thuật được bầu định kỳ. Dự án được bảo trợ bởi Django Software Foundation (DSF), thành lập năm 2008. |
| **Nguồn tài chính** | Quyên góp cá nhân/doanh nghiệp qua DSF, chương trình Corporate Membership, tài trợ vị trí bảo trì chính thức (Django Fellows) được trả lương từ quỹ DSF. |
| **Đánh giá tình trạng** | Tốt — dự án hoạt động ổn định gần 20 năm, có tổ chức phi lợi nhuận đứng sau (giảm rủi ro phụ thuộc 1 cá nhân/doanh nghiệp), lịch phát hành đều đặn, cộng đồng lớn, tài liệu đầy đủ, có cơ chế tài trợ vị trí bảo trì chính thức. |
